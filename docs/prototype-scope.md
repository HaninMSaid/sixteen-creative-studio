# Current prototype scope — revised 11 October 2026

This document incorporates the user's corrections during the first review.

## Included

- Home: edge-to-edge, full-viewport antique atelier image with the Sixteen wordmark overlaid; restrained scroll motion; studio manifesto; full-image NK Villa introduction; 360° collection invitation.
- NK Villa: concept, materials and execution story with sample imagery clearly identified.
- Objects of Desire: standing-position 360° room with four antique compositions. Drag/swipe or keyboard to look around. The objects themselves receive a warm tint on hover and open detail panels on selection. No visible plus markers. Corner buttons orient the camera; an equivalent object list supports accessible selection.
- Consultation: service → demonstration calendar/time → client and project information → review. Fields include name, email, mobile, location, project type, area, stage and brief. Optional file selection records filenames only. Validation uses native browser controls.

## Deliberately deferred by the user

Connect the studio email and actual calendar after prototype review. Current dates/times are illustrative, no slot is reserved, no notification is sent, and no booking is made. Personal details stay only in React state until reload or navigation; no database, browser storage or analytics receives them. Selected files are not uploaded.

Live payments, inventory, authentication and CMS remain out of scope.

## Content policy

The generated antique room demonstrates the interaction and atmosphere. It does not claim to contain real pieces from the creative director's collection. Replace it with approved 360° photography or an approved room render and actual object records. The current experience supports looking around from a fixed point; it does not provide free walking through a 3D model.

NK Villa photos, drawings, project facts, actual antique provenance/materials/dimensions and consultation fees still need approval. Price is shown as “Price on enquiry” until verified.
